木雷短链助手

配置 API 后即可在浏览器中管理短链并一键生成当前页短链

欢迎使用

请先完成以下配置，才能使用短链管理功能。

  1. 登录您的木雷短网址管理后台
  2. 进入 Token 管理，创建类型为 签名认证（signature） 的 Token
  3. 创建成功后，请妥善保存 App ID 和 App Secret（仅显示一次）
  4. 将下面三项填写完整并保存
